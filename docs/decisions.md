# Decisions

1. **Repository evidence first.** Actual Git changes and independent checks add a new
   capability beyond the owner's existing agent-state and integration projects.
2. **Exact-byte execution gate.** The host lacks an adequate hostile-code boundary.
   Path allowlists alone cannot prevent malicious code in an allowed app.py.
3. **Deterministic default.** Recruiters and CI need no paid API. The optional structured
   planner does not establish live quality and cannot weaken execution policy.
4. **One process and SQL.** Two threads, unique reservations and conditional claims fit
   this reference. SQLite simplifies onboarding; PostgreSQL is the optional service path.
5. **Prepare before publishing.** A green candidate creates a digest-bound artifact.
   Publication is a separate operator action. Unknown write outcomes are never blindly retried.
6. **Preserve portfolio boundaries.** Discovery read public READMEs for Bounded Agent Runtime,
   Production Integration Reference, Full-Stack AI Operations Console and the portfolio.
   No source was copied; none was modified. A separately named Knowledge Workflow Runtime
   was not found in the accessible repository listing, so its implementation was not assumed.

No general autonomy, production usage, business impact, seniority or experience duration
is inferred from this project.
