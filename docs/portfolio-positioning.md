## Concise portfolio description

Built an auditable issue-to-PR workflow using Python/FastAPI and Next.js. A real GitHub issue
produced a tested one-line fix and a reviewable draft PR. The system binds changes to human
approval, records command outputs and diffs, and rejects failed verification. A free public
viewer lets reviewers explore authentic, clearly labeled recordings. Execution is limited to
reviewed fixtures; general autonomous coding and live model quality are not claimed.

Technologies: Python, FastAPI, Pydantic, SQLAlchemy, SQLite/PostgreSQL, GitHub REST API,
pytest, Ruff, mypy, Next.js, TypeScript, React, Docker Compose and GitHub Actions.

Inspectable evidence: [Issue #1](https://github.com/naraya07pedro-spec/repopilot-ai/issues/1),
[draft PR #2](https://github.com/naraya07pedro-spec/repopilot-ai/pull/2), the
[public demo](https://naraya07pedro-spec.github.io/repopilot-ai/) and
[verification records](evidence.md). Test counts are tied to exact revisions in the evidence
report, rather than presented as permanent portfolio metrics.

Position this as evidence of backend workflow engineering, authorization boundaries, Git
automation, failure handling and verification discipline. Do not imply customers, production
usage, business impact or additional professional experience. The private workspace and isolated
worker are outside this portfolio release's completed scope. No existing portfolio was edited;
this copy is prepared for the owner's review and later integration.
